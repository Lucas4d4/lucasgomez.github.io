PROYECTO 3: "Base de datos Juegos"



Lenguajes de programación de base de datos utilizados: SQL.



Base de datos que permite almacenar toda la información sobre juegos, desarrolladores, categorías, plataformas, usuarios, tiendas y opiniones. Esta información también puede ser actualizada, por ejemplo, ante una nueva rebaja de un determinado juego en una determinada tienda.

Dicha base de datos sirve para un sistema que tiene como objetivo nuclear la información de juegos de múltiples plataformas, incluyendo de qué tratan, por dónde se pueden conseguir y dónde encontrar los mejores precios. También, dentro del sistema, los usuarios pueden registrarse para dejar una puntuación de cada juego con un comentario optativo, o guardar el artículo en una lista personal.

-Se crearon las tablas con sus correspondientes campos. Cada tabla tiene uno o más campos que actuan como Primary Key (Clave Primaria) o Foreign Key (Clave Foránea).

-Se crearon los correspondientes procedimientos almacenados para la ejecución de rutinas almacenadas o funciones dentro de la base de datos. Por ejemplo: un procedimiento almacenado que sirve para agregar usuarios, otro para modificar los usuarios, etc.

-Se crearon los triggers para la ejecución automática de diferentes métodos o funciones cuando se produzca un evento en el servidor de bases de datos.

-Se creó un DER para la muestra gráfica de las tablas con sus respectivas claves (Primarias o Foráneas) y las conexiones entre las tablas
