PROYECTO 1: "Project Bank"



Lenguajes de programación utilizados: JavaScript, JSP (JavaServer Pages), MySQL, Html y CSS.



Sistema de gestión para un banco en donde existen dos tipos de usuarios: administrador del banco y clientes.

Los usuarios que son administradores pueden realizar las siguientes acciones:

- Crear, modificar, eliminar y listar clientes para el banco. A cada cliente se le puede asignar un nombre de usuario y contraseña para que pueda acceder a la página web del banco. El administrador puede modificar la contraseña del cliente pero nunca el usuario del mismo.

-Crear, modificar, eliminar y listar cuentas y asignar cuentas a clientes. Una cuente puede pertenecer a un solo cliente. Se puede asignar un máximo de 3 cuentas para un cliente. Al crear una cuenta, se le asigna automáticamente un monto inicial de $10000.

-Autorización de préstamos. El administrador puede autorizar o rechazar los préstamos solicitados por el cliente. Si se aprueba el préstamo entonces se le asignará al cliente el monto pedido.

Los usuarios que son clientes pueden realizar las siguientes acciones:

-El cliente puede seleccionar una cuenta y observar el historial de los movimientos realizados en esa cuenta.

-Transferencias a otros clientes: El cliente puede transferir dinero entre sus propias cuentas o a cuentas de otros clientes utilizando el CBU. Se puede realizar la transferencia mientras el usuario cuente con dinero disponible. Si no posee dinero no se podrá realizar la transferencia.

-Pedido de préstamo. El cliente puede pedir un préstamo de cierto dinero al banco, seleccionar la cantidad de cuotas en las que quiere abonarlo y elegir la cuenta en donde se le depositará el pago del préstamo. El banco recibirá el pedido y autorizará o no dicho préstamo.

-El cliente tiene un menú de pago de préstamos en donde figura las cuotas que debe pagar, puede pagar seleccionando la cuota y cuenta de donde sedescontará dicho gasto. Cada vez que se pague una cuota se guardará la fecha en la cual se pagó la misma.

- El cliente puede visualizar su información personal. No puede cambiar los datos, solo los visualizará.
